# 레인 포인트 웹사이트

아파트에 모인 빗물만큼 관리비를 돌려받는 주민참여형 빗물 보상 제도, 레인 포인트(Rain Point)의 웹사이트입니다.
2026 대한민국 물산업 혁신 창업대전 아이디어 부문(물이용) · 팀 늙치즈

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 첫 화면. 관리자 대시보드와 주민 앱으로 들어가는 입구 |
| `admin/index.html` | 관리자 대시보드 (현황 → 보상 설계 → 참여 검증 → 운영 추천) |
| `app/index.html` | 주민용 웹앱. 휴대폰 홈 화면에 앱처럼 설치 가능(PWA) |
| `app/manifest.webmanifest` | 앱 이름·아이콘·색 설정 (설치용) |
| `app/sw.js` | 한 번 열면 오프라인에서도 열리게 하는 파일 |
| `app/dong.js` | 82개 법정동의 공동주택 건축면적·세대수 |
| `app/icons/` | 앱 아이콘 |

모든 페이지는 HTML 파일 그대로 동작합니다. 빌드나 설치가 필요 없습니다.

## 내 컴퓨터에서 미리 보기

`index.html`을 더블클릭해도 열리지만, 주민 앱의 설치·오프라인 기능은 서버에서만 동작합니다. 이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:8000` 을 여세요.

```
python -m http.server 8000
```

## GitHub Pages로 무료 배포하기

1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예: `rainpoint` (Public)
2. 저장소 화면에서 **Add file → Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 모두 끌어다 놓은 뒤 **Commit changes**를 누릅니다. `index.html`이 저장소 맨 위에 있어야 합니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 정하고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<GitHub 아이디>.github.io/rainpoint/` 주소로 열립니다.

주소가 https라서 주민 앱의 **홈 화면에 추가**(설치)도 바로 됩니다.
- 안드로이드 Chrome: 주민 앱 → 안내 탭 → ‘홈 화면에 추가’ 버튼, 또는 브라우저 메뉴 → 앱 설치
- 아이폰 Safari: 공유 버튼 → ‘홈 화면에 추가’

Netlify(app.netlify.com/drop)에 폴더를 끌어다 놓는 방법도 같은 결과를 냅니다.

## 고칠 때 알아 둘 점

- **주민 앱을 고친 뒤**에는 `app/sw.js`의 `VERSION` 값(예: `rp-app-v1` → `rp-app-v2`)을 올려야 이미 설치한 휴대폰에도 새 버전이 반영됩니다.
- **정책 조건**(환급률 60%, 상한 11,000원, ㎥당 1,100원)은 `app/index.html` 스크립트 맨 위 `RATE`, `CAP`, `PRICE`에 있습니다. 관리자 대시보드는 화면의 슬라이더로 바꿉니다.
- **예시 시점**은 주민 앱의 `NOW_MONTH`(기본 8월)입니다.
- **AI 인사이트 연결(선택)**: 지금 관리자 대시보드의 정책 인사이트는 수치로 만든 규칙 기반 요약입니다. AI를 붙이려면 Claude API를 호출하는 작은 서버 함수를 만들고, `admin/index.html` 맨 위의 `window.RP_CONFIG = { aiEndpoint: "" }`에 그 주소를 넣으면 됩니다. 서버는 `{"prompt": "..."}`를 받아 `{"text": "..."}`를 돌려주면 됩니다. API 키는 절대 HTML에 넣지 말고 서버에만 둡니다.

## 데이터와 한계

- 건축HUB(국토교통부) 건축물대장 표제부, 2026.8 기준, 서울 8개 구(강남·서초·송파·강동·관악·광진·동작·성동) 공동주택
- 기상청 서울 평년값(1991~2020): 연 1,417.9mm, 월별 강수량
- 서울특별시 빗물이용시설 공간정보(서울 열린데이터광장 SP_LGRC_AS, 2022-04-03 기준). 위치·등록번호만 있어 건물 용도와 용량은 알 수 없음
- 저류조 최소 용량: 물의 재이용 촉진 및 지원에 관한 법률 시행규칙 제4조(지붕 집수면적 × 0.05m 이상)
- 금액은 건축면적 × 연강수량 × 유출계수 0.85로 계산한 **잠재량 기준**입니다. 참여 검증·운영 추천 화면의 수위·예보와 주민 앱의 알림은 **시연용 예시**입니다.
